# Сайт бани в Эсто-Садке (Красная Поляна)

Сайт для бани на Листопадной ул., 17
([карточка на Яндекс Картах](https://yandex.ru/maps/org/banya/82869232512/)).
Его задача — довести человека до сообщения в WhatsApp или до звонка.

**`index.html` — готовый сайт одним файлом.** Внутри лежат стили, скрипты,
шрифты и фото. Его можно открыть двойным щелчком, отправить файлом или залить
на хостинг рядом с `og.jpg`.

## Как устроена страница

Страница идёт по ходу визита. У каждой главы свой цвет:

| Раздел | Цвет | Что внутри |
|---|---|---|
| Первый экран | утренний туман | заголовок, кнопка WhatsApp, телефон, оценка 5,0; справа запотевшее панорамное окно |
| Дорога | туман | как добраться на джипе, отзыв Ольги, ссылка «где встречаемся» |
| Пар | тёмное дерево | парная, программы парения, отзыв Виктории |
| Вода | родник | купель и чан, отзыв гостьи |
| Огонь | угли | камин, чай, что выдаём, отзыв Анны |
| Сколько стоит | бумажный прейскурант | «Аренда — от 15 000 ₽», доп. программы, отзыв Алексея о ценах |
| Фото | ночь | лента: тянется мышью, листается кнопками, по клику фото открывается крупно |
| Записаться | ночь | конструктор сообщения (ниже) |
| Как найти | ночь | адрес, часы, телефон, карта, ссылка на отзывы |

**Запотевшее окно.** Три створки с фото закрыты «запотевшим стеклом» — это
холст canvas поверх фото. При загрузке по стеклу проходит волна. Курсор или
палец стирают туман, по протёртому стекают капли. Через 6–9 секунд без касаний
стекло отпотевает само, и фото видно всем. Вертикальная прокрутка на телефоне не блокируется: протирать нужно
движением вбок. Если в системе включено «уменьшение движения», тумана нет.

**Конструктор сообщения.** Человек отмечает число гостей, дату, парение и повод,
а справа сразу собирается текст:

```
Здравствуйте! Меня зовут Анна. Хочу забронировать баню.
Нас будет 3–4 человека.
Хотим приехать 17 октября (суббота).
Интересует обрядное парение.
Повод — день рождения.
Подскажите, пожалуйста, свободное время и стоимость.
```

Текст можно поправить вручную. Кнопка «Отправить в WhatsApp» открывает чат с этим
текстом, остаётся нажать «Отправить». Ни одно поле не обязательно: без отметок
уходит короткое «Хочу забронировать баню…».

**Плавающая кнопка.** На телефоне после первого экрана внизу появляются
«Написать» и «Позвонить», на компьютере — кнопка WhatsApp в углу. Пока на экране
запись или контакты, кнопки прячутся.

## Что поменять перед запуском

### Контакты

Блок настроек стоит в самом конце `index.html` (ищите «НАСТРОЙКИ САЙТА»)
и в `src/config.js`:

- `phone`, `phoneDisplay`, `whatsapp` — номер +7 (938) 445-59-87 из карточки
  на Яндекс Картах. **Проверьте, что на нём есть WhatsApp.**
- `telegram` — ссылка вида `https://t.me/имя`. Если её вписать, появятся кнопки
  Telegram: на случай, если у клиента не работает WhatsApp.
- `metrikaId` — номер счётчика Яндекс Метрики.

Номер ещё прописан в тексте страницы для поисковиков. При смене номера найдите
и замените `79384455987` и `445-59-87` во всех файлах `src/`, затем пересоберите.

### Что подтвердить у владельца

Всё на сайте взято из карточки на Яндекс Картах и из отзывов гостей:

- [ ] **Цена «от 15 000 ₽».** В карточке указано «15 000–100 000 ₽».
- [ ] **«Наверх возим на джипе».** Так пишут в отзывах («ребята привозят сами
      на место», «добраться можно только на джипе»). Уточните, где встреча
      и входит ли дорога в цену.
- [ ] **Что входит в аренду:** аромапарение, купель и чан, чай с вареньем и мёдом,
      халаты и полотенца (из описания на Яндексе).
- [ ] **Программы:** классическое парение с мастером, обрядное, скраб, массаж.
- [ ] **Часы:** ежедневно с 9:00 до 00:00.

### Фото

Сейчас стоят **временные фото, вырезанные из скриншотов Яндекс Карт**. Каждое
около 240 px. В тумане и на маленьких «отпечатках» это незаметно, но крупно они
мягкие. Попросите оригиналы у владельца и положите в `src/img/` под теми же
именами:

| Файл | Где на сайте |
|---|---|
| `view-mountains.jpg`, `pool-stone.jpg`, `sauna-night.jpg` | запотевшее окно на первом экране (лучше вертикальные) |
| `valley.jpg`, `deck.jpg` | Дорога |
| `steam-room.jpg`, `sauna-night.jpg` | Пар |
| `plunge-forest.jpg`, `pool-stone.jpg`, `view-mountains.jpg` | Вода |
| `fireplace.jpg`, `tea.jpg`, `terrace.jpg` | Огонь |
| все, включая `swing.jpg` и `glass-deck.jpg` | лента «Фото» |

Размер не важен: сборка сама уменьшит фото до 1600 px и сожмёт в WebP (если
установлен Pillow: `pip install pillow`). Поправьте у тега `<img>` атрибуты
`width` и `height` под пропорции нового фото, чтобы страница не прыгала при загрузке.

На `view-mountains.jpg` вдалеке лежит человек. При замене берите кадры без гостей
или те, на публикацию которых есть согласие.

## Как пересобрать

Правки делаются в `src/`, потом:

```bash
python3 build.py
```

Скрипт собирает `index.html`. Каждое фото кладётся в файл один раз, повторы
подставляет скрипт страницы. Заодно текст проходит через типограф:
- после коротких предлогов и союзов ставится неразрывный пробел;
- тире не переносится в начало строки;
- слова через дефис («пар-мастер», «Эсто-Садок») не разрываются.

## Яндекс Метрика

1. Создайте счётчик на metrika.yandex.ru и впишите номер в `metrikaId`.
2. Заведите цели типа «JavaScript-событие»:

| Цель | Когда срабатывает |
|---|---|
| `whatsapp` | любая кнопка WhatsApp (в параметре `place` — какая именно) |
| `call` | нажатие на телефон |
| `telegram` | кнопка Telegram |
| `book_start` | первая отметка в конструкторе сообщения |
| `book_send` | «Отправить в WhatsApp» из конструктора |
| `glass_wipe` | человек протёр запотевшее окно |
| `photo_open` | открыл фото крупно |

С Метрикой сайт собирает cookie. По 152-ФЗ тогда нужны политика
конфиденциальности и уведомление о cookie. Форм с личными данными на сайте нет:
сообщение человек отправляет сам из своего WhatsApp.

## Как выложить

Загрузите на хостинг (Timeweb, Beget, REG.RU, Netlify, GitHub Pages) два файла:
`index.html` и `og.jpg`. После этого:

- впишите полный адрес картинки в `<meta property="og:image">`
  (`https://ваш-домен/og.jpg`), иначе превью в мессенджерах не появится;
- добавьте сайт в Яндекс Вебмастер;
- добавьте ссылку на сайт в карточку на Яндекс Картах. Сейчас ссылок там нет,
  и у карточки нет подтверждённого владельца — это делается через Яндекс Бизнес.

## Структура

```
index.html        готовый сайт одним файлом (собирается, руками не править)
og.jpg            превью ссылки для мессенджеров, кладётся рядом с index.html
build.py          сборка src/ → index.html
src/index.html    разметка
src/style.css     стили (цвета глав и шрифты — в начале файла)
src/main.js       запотевшее окно, конструктор сообщения, лента фото, просмотр
src/config.js     контакты, Telegram, Метрика
src/img/          фото
src/fonts/        Old Standard TT и Golos Text (лицензия OFL, тексты лицензий там же)
```
